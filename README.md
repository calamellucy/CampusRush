# Campus Rush v3.0.0

### 프로젝트 설명

지각 위기에 처한 대학생이 지각하지 않기 위해 달리는 러너 게임.

Unity 2D 기반 팀프로젝트.

---

### v3.0.0 주요 업데이트 상세

#### 1. 제한 시간 및 엔딩 시스템 추가

- 3분 제한 시간 추가
  - 게임 화면에 남은 시간 표시
  - 제한 시간 동안 생존하면 학교 도착 엔딩으로 이동
  - HP가 0이 되면 지각 엔딩으로 이동

- 최종 학점 계산 로직 추가
  - 최종 점수에 따라 A+, A0, B+, B0 등 학점이 계산되도록 구현
  - 엔딩 화면에서 최종 점수와 최종 학점을 함께 표시

- 엔딩 분기 구현
  - 학교 도착 엔딩과 지각 엔딩을 구분하여 표시
  - 엔딩 종류에 따라 배경 이미지와 자막 내용이 다르게 출력됨

- 엔딩 화면 연출 개선
  - 엔딩 자막 효과 추가
  - 마지막 자막 이후 최종 점수와 최종 학점 표시
  - 결과 표시 이후 다시하기/메인화면 버튼 표시

#### 2. 장애물 및 아이템 스폰 밸런싱 개선

- 게임 진행에 따라 장애물, 아이템 등 오브젝트 이동 속도가 점진적으로 증가하도록 구현

- 장애물 생성 간격 조정
  - 고정 간격 생성 방식에서 최소/최대 간격 사이의 랜덤 생성 방식으로 변경
  - 시간이 지날수록 생성 간격이 줄어들도록 조정하여 후반부 난이도 상승

- 아이템 생성 방식 개선
  - 아이템 Y 위치를 low/middle/high 중 랜덤으로 생성
  - 아이템 생성 간격도 최소/최대 간격 사이 랜덤값으로 결정되도록 수정

- 오브젝트 최소 간격 관리
  - 장애물, 아이템, NPC가 지나치게 겹쳐 생성되지 않도록 최소 생성 간격 적용
  - NPC 이벤트 등장 시 아이템/장애물 스폰을 잠시 제어하여 겹침 문제 개선

#### 3. 플레이어 조작 및 상태 효과 개선

- 점프 도중 아래 방향키 입력이 씹히지 않고, 지면 착지 즉시 숙이기 상태로 전환되도록 수정
- 무적 상태 깜빡임 효과를 추가하여 피격 후 무적 상태를 사용자가 직관적으로 확인할 수 있도록 개선
- 플레이어 스프라이트 및 애니메이션 관련 에셋 개선

#### 4. UI 및 시각적 연출 개선

- 시작 화면 버튼 디자인과 문구를 게임 전체 UI 분위기에 맞게 수정
- 시작 화면에서 게임 방법 버튼을 통해 조작법과 규칙을 확인할 수 있도록 구현
- 주요 UI 텍스트에 검정색 테두리를 적용하여 점수, 시간, HP 등 플레이 중 필요한 정보가 더 잘 보이도록 수정
- 플레이어, 장애물, 아이템이 배경과 더 잘 구분되도록 배경 시각 요소 개선
- 점수 아이템 획득 시 +점수 또는 -점수가 화면에 표시되도록 구현
- 이벤트 적용 시 플레이어에게 시각적 이펙트가 표시 추가

#### 5. 사운드 및 기타 개선

- 효과음 추가
  - 아이템 획득, 장애물 충돌, 버튼, 점프, 숙이기, 이벤트 효과음 적용

- 한글 주석이 깨지지 않도록 인코딩 문제 수정

### 주요 기능 (요약)

- 플레이어: 기본 조작(점프, 이단 점프, 숙이기) 가능, 충돌 후 무적 상태 적용
- 시스템: HP 시스템, 3분 제한 시간, 엔딩 분기, 최종 점수 및 학점 계산
- 오브젝트: 학점 아이템, 커피 아이템, 체력 회복 아이템, 장애물, 자동차 장애물, NPC 이벤트
- 이벤트: 교수님, 연애, 깡패 NPC 이벤트에 따른 버프/디버프 적용
- UI/연출: 시작 화면, 게임 방법 화면, 점수 표시, 시간 표시, 엔딩 자막, 효과음, 버프 시각 효과

### 설치 및 설정 방법

#### 플레이 방법

1. `CampusRush_v3.0.0_Windows.zip` 파일 다운로드

2. 압축 해제

3. 압축 해제된 폴더 안의 `Campus Rush.exe` 파일 실행

#### Unity Editor로 실행하는 방법

1. GitHub 저장소를 클론

```
git clone 저장소_URL
```

2. 프로젝트에 맞는 Unity 버전으로 프로젝트 열기

3. Assets/Scenes 폴더에서 StartScene을 열고 실행

---

#### 조작 방법 및 규칙

조작:

- 위쪽 방향키(점프/2단 점프)
- 아래쪽 방향키(숙이기)

규칙:

- 제한 시간 3분 동안 생존하면 학교 도착 엔딩으로 이동
- 제한 시간 전에 HP가 0이 되면 지각 엔딩으로 이동
- 장애물 충돌 시 HP -1
- 체력 아이템 획득 시 HP +1
- 커피 아이템 획득 시 점수 증가 및 HP -1
- 학점 아이템 획득 시 점수 증가 또는 감소
- NPC 이벤트 발동 시 일정 시간 동안 점수 배율 변동 적용

### 기여 방법

브랜치 전략: Git Flow

- main: 최종 배포 브랜치
- develop: 개발 통합 브랜치
- feature/\*: 기능 개발 브랜치
- release-\*: 릴리즈 준비 및 QA 브랜치
- fix/\*: 버그 수정 브랜치
- hotfix/\*: main 배포 후 긴급 수정 브랜치

작업 방식

- Issue 탭에 이슈 등록
- develop 브랜치에서 feature 브랜치 생성
- 기능 구현 후 Pull Request 생성
- 코드 확인 및 테스트 후 develop 브랜치에 병합
- 병합 후 해당 feature 브랜치 삭제
